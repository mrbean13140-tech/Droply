# Droply

Минимальный файлообменник для LXC на Proxmox: один статический Go-бинарник работает как PID 1 (без ОС и shell внутри), поднимает сеть, cloudflared-туннель и веб-интерфейс (PWA) для отправки/скачивания файлов с iPhone/Android/ПК.

- Доступ снаружи — только через Cloudflare Tunnel + Cloudflare Access (или режим с паролем для KeenDNS).
- Сервис слушает 127.0.0.1, работает под отдельным uid, загрузки — чанками с докачкой.
- Многопользовательский: у каждого свой логин, свои файлы, ссылки и квота (по умолчанию 1 ГБ). Регистрация открытая (админ может закрыть; лимит 20 пользователей и 3 регистрации с IP в сутки) или пользователей заводит администратор; первого администратора — страница настройки. Двухфакторная аутентификация (TOTP, Google Authenticator и аналоги) обязательна для всех; админ может сбросить её пользователю. Вход через Cloudflare Access — автоматически по e-mail пользователя.
- Секреты в шаблоне не хранятся: токен, пароль и e-mail задаются на странице настройки `http://IP:8081` (первый раз открыта, дальше — по текущему паролю) и хранятся на томе данных (root, 0600). Если задан пароль, веб-интерфейс доступен и из локальной сети: `http://IP:8080`.

Прямой HTTPS: `tls_listen` + `tls_domain` — Droply сам получает и продлевает сертификат Let's Encrypt (ACME, проверка TLS-ALPN-01 через тот же порт, порт 80 не нужен).

Вход через KeenDNS роутера: запросы с адресов `proxy_ips` считаются внешними (IP из X-Real-IP, без прав админа).

Сборка: `CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o droply .`, шаблон — см. `build-rootfs.sh`.

## Установка на Proxmox
Шаблон: `dist/droply-rootfs.tar.gz` (SHA256 рядом). Скачать в хранилище шаблонов:
`https://raw.githubusercontent.com/mrbean13140-tech/droply/main/dist/droply-rootfs.tar.gz`
Создать LXC: `ostype=unmanaged`, unprivileged, 192 МБ ОЗУ, том `/data` с `mountoptions=noexec;nosuid;nodev`. Сеть задаётся в `/etc/landrop.json` шаблона (`etc-landrop.json`).
